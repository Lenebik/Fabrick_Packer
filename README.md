Консольное приложение на Haskell для автоматической раскладки швейных лекал (выкроек) на ткани с целью минимизации расхода материала. Программа принимает растровое изображение с контурами лекал, восстанавливает их полигональное представление и строит плотную раскладку на ткани заданной ширины с использованием геометрических эвристик.

Использовано:

⦿ выделение связных компонент (BFS, 8-связность),

⦿ трассировка границы (алгоритм Мура),

⦿ упрощение полигонов (алгоритм Рамера–Дугласа–Пекера).

⦿ раскладка на ткани фиксированной ширины
на основе No-Fit Polygon (NFP) и Bottom-Left Fill (BLF) эвристики,


Технологии:

⦿ Язык: Haskell (GHC)

⦿ Сборка: Stack

Библиотеки:

⦿ JuicyPixels — чтение и запись изображений,

⦿ aeson — работа с JSON,

⦿ containers, directory, time — вспомогательные модули.

Требования:

⦿ GHC (рекомендуется версия, указанная в stack.yaml)

⦿ Stack (https://docs.haskellstack.org)
